# 범용 에이전트 하네스 참고 문서

작성일: 2026-10-23 (Asia/Seoul)

이 문서 묶음은 **카카오톡으로 여러 작업환경의 에이전트에 지시하고 상태를 확인하는 범용 하네스**를 별도 GitHub 저장소에서 개발하기 위한 참고 자료다. 현재 Web-Kakao의 제품 구조를 변경하거나 새 하네스를 설치한 결과물이 아니다.

원본 분석과 새 설계 제안은 구분했다. 범용 참고서의 객체·명령·상태·파일 배치는 **새 제품을 위한 제안**이며 원본 저장소에 이미 구현된 기능으로 해석하면 안 된다.

## 사용자 요구사항

1. Windows·macOS·Linux에 설치할 수 있는 공통 하네스와 환경별 실행기를 제공한다.
2. 특정 에이전트 제품 하나에 고정하지 않고 여러 실행 도구를 연결한다.
3. 카카오톡으로 기기·프로젝트·에이전트를 지정해 작업을 요청한다.
4. 추가 지시가 기존 작업의 문맥을 이어갈 수 있도록 작업과 세션을 연결한다.
5. `/대시보드`로 작업 목표, 총괄·하위 에이전트, 진행 단계, 확인 대기, 연결 상태를 조회한다.
6. 결과와 중요한 상태 변화를 카카오톡으로 회신한다.
7. 구현 결과는 이후 별도 GitHub 저장소에서 관리한다.

여기서 여러 OS 지원과 여러 에이전트 도구 지원은 서로 다른 검증 축이다. 어느 한쪽의 설치 성공으로 다른 축까지 지원된다고 판정하지 않는다.

## 별도 레포로 옮기는 방법

이 디렉터리는 내부 링크를 상대경로로 작성했다. 폴더 단위로 새 저장소의 문서 디렉터리에 복사해 읽을 수 있다. 원본 근거 링크는 분석 당시 커밋에 고정돼 있어 이후 원본 변경과 분리된다.

새 저장소에는 선별한 설계 문서와 검토한 코드·라이선스를 옮긴다. 인증 정보, 실제 대화·사진, 기기 등록 자료, 개인 설정, 실행 중 세션, 로컬 절대경로를 설정 기본값으로 옮기지 않는다. 현 저장소의 `.agents/`·`.codex/`·`.harness/`는 Web-Kakao 작업 규칙이므로 새 제품의 규칙으로 채택하기 전에 범위와 전제를 다시 검토한다.

이 문서 작성으로 새 저장소 생성, 코드 복사·통합, 커밋·push, 실제 계정 실험이 승인되거나 수행된 것은 아니다.
