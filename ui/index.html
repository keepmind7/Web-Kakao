Web-Kakao UI 시안

가짜 데이터로 만든 화면입니다. 방 클릭, 필터·검색, 설정 열기, 오픈채팅(읽기 전용) 상태를 눌러볼 수 있습니다.

A · 클래식 정돈형익숙한 카카오톡 배치. 노란 내 말풍선, 하늘색 대화 배경. 머리글 버튼 5개를 아이콘 3개와 ⋯ 메뉴로 정리하고, 연결 설정은 왼쪽 서랍.
B · 다크 작업공간형Slack·Discord 같은 3단 구성. 아이콘 레일 + 목록 + 대화 + 오른쪽 방 정보 패널. 말풍선 대신 목록형 메시지, 마우스를 올리면 답장·복사 버튼.
C · 미니멀 집중형iMessage 느낌의 밝고 여백 많은 화면. 둥근 카드, 파란 말풍선, 떠 있는 입력창. 방 제목을 누르면 고정·알림·이름 변경 시트.
