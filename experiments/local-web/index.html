연결 정보와 저장 범위

등록 요청 프로필은 Android 태블릿 SM-T733입니다. 프로그램은 이 노트북에서 실행됩니다. 휴대폰 카카오톡으로 QR을 스캔하고 연결 기기를 확인해 주세요.

로그인 정보와 대화·사진은 서버 메모리에만 보관합니다. 인증 보관 한도는 1시간이며 카카오 서버의 실제 만료 시간은 아닙니다. 로컬 세션 삭제는 원격 로그아웃을 뜻하지 않습니다.

개인 설정 저장을 켜면 이름·고정·알림·읽음 옵션을 이 노트북에서 계정별로 보관하고 다음 로그인에 복원합니다. 로그인 정보·메시지·사진은 저장 대상이 아닙니다. 저장하지 않아도 같은 계정 연결 동안 새로고침과 재접속에 설정을 유지합니다.

대화 검색은 현재 불러온 최대50개 메시지만 대상으로 합니다. 복사는 누른 메시지의 표시 내용을 클립보드에 넣습니다. 브라우저 알림은 웹이 열려 있는 동안 본문 없이 무음으로 표시하며, 방별로 꺼도 새 메시지 숫자는 유지합니다.

목록의 숫자는 이 웹에서 확인하지 않은 새 메시지 수입니다. 메시지 옆 숫자는 서버에서 읽음 상태를 확인할 수 있을 때만 표시합니다. 읽음 동기화를 켜면 선택한 방의 최신 메시지를 실제로 확인했을 때 카카오톡에 읽음을 알립니다.

지원되는 방의 메시지에서 답장을 선택해 원문을 인용할 수 있습니다. ＋에서 JPEG·PNG·WebP 사진을 선택하고 미리보기에서 보내기를 누르면 사진 한 장을 보냅니다. 변환 후 10MiB 이하만 지원하며 사진 원본 파일·위치 정보는 저장하지 않습니다. 파일·동영상·사진 묶음 전송은 포함하지 않습니다.
