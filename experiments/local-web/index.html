로그인 정보와 대화·사진은 서버 메모리에만 보관합니다. 인증된 웹카카오 탭의 연결이 유지되는 동안에는 1시간이 지나도 계속 사용합니다. 마지막 탭의 연결이 닫히면 2분 후 대화 연결을 종료하고 인증 정보를 지웁니다. 절전·브라우저의 탭 중단 등으로 연결이 끊긴 경우도 같은 유예 시간을 적용합니다. 카카오 서버가 인증을 만료시키거나 연결을 해제할 수 있습니다. 로컬 세션 삭제는 원격 로그아웃을 뜻하지 않습니다.

개인 설정 저장을 켜면 이름·고정·알림·읽음 옵션을 이 노트북에서 계정별로 보관하고 다음 로그인에 복원합니다. 로그인 정보·메시지·사진은 저장 대상이 아닙니다. 저장하지 않아도 같은 계정 연결 동안 새로고침과 재접속에 설정을 유지합니다.

목록의 숫자는 로그인 때 서버가 알려 준 미읽음 수와 이후 이 웹에서 확인하지 않은 새 메시지 수를 합한 값입니다. 모바일의 현재 미읽음 수와 다를 수 있습니다. 메시지 옆 숫자는 서버에서 읽음 상태를 확인할 수 있을 때만 표시합니다. 조회 읽음 동기화를 켜면 선택한 방의 최신 메시지를 실제로 확인했을 때 카카오톡에 읽음을 알립니다. 직접 문자·답장·사진을 보내면 이 옵션과 관계없이 해당 방의 읽음도 동기화하며 기존 상대 메시지도 읽음 처리될 수 있습니다.
