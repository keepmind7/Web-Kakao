# 처음 사용하는 사람을 위한 설치·운영 안내

Web-Kakao는 본인 PC에서 실행하는 로컬 앱입니다. 공유받은 소스 ZIP 또는 Git clone을 준비한 뒤 그 PC에서 런타임과 의존성을 설치합니다. 다른 사람의 `local-only/`·개인 저장소·로그인 파일을 복사하지 마세요. OS별 검증 범위와 기능 제한은 [README](../README.md#지원-환경과-현재-상태)를 먼저 확인하세요.

## 처음 실행하기

1. Python3.11 이상과 Chrome·Chromium·Edge 중 하나를 설치합니다. 소스 ZIP은 새 폴더에 압축을 풉니다. Windows에서는 짧은 경로, 예를 들어 `C:\src\web-kakao`를 권장합니다.
2. 터미널에서 그 폴더로 이동해 [README의 준비 명령](../README.md#설치)을 순서대로 실행합니다. 처음에는 네트워크가 필요합니다. Node는 도구가 OS에 맞는 고정 버전을 준비합니다.
3. 로그인하기 전 다음 명령으로 로컬 서버를 시험할 수 있습니다. Windows는 `python3` 대신 `py -3.11`을 사용합니다.

```bash
python3 tools/local_web.py start --mock
python3 tools/local_web.py open --browser chrome
python3 tools/local_web.py status
```

이 단계는 화면과 로컬 실행 확인입니다. 카카오 계정의 실제 연결·메시지 수신 성공을 확인하는 검사는 아닙니다. mock 점검을 마치면 설정의 **로컬 세션 지우기**를 누르고 `python3 tools/local_web.py stop`으로 종료한 뒤 다음 단계로 진행합니다.

4. 실제 사용은 다음 명령으로 시작합니다.

```bash
python3 tools/local_web.py start --gap-probe --messaging
python3 tools/local_web.py open --browser chrome
```

새로 열린 창에서 QR 로그인을 승인하고 **대화방 불러오기**를 누릅니다. 주소창에 서버 주소를 직접 넣은 탭에는 접근 권한이 없습니다. `--messaging`을 빼면 읽기 전용으로 시작합니다. 다른 옵션으로 실행 중인 서버를 자동 교체하지 않습니다.

## 매번 사용할 때

- 대화 조회 시 읽음 알리기는 기본 OFF입니다. 직접 메시지를 보낸 방의 읽음 동기화와는 동작이 다르므로 [읽음 안내](../README.md#사용할-때-알아둘-것)를 확인하세요.
- 사진을 여러 장 받으면 화면 근처 이미지부터 순서대로 불러옵니다. 사진이 늦게 뜨는 것과 대화 서버 연결 종료는 다른 상태입니다.
- 발송 결과가 불명확하면 휴대폰에서 먼저 도착 여부를 확인하세요. 앱은 불명확한 발송을 자동으로 반복하지 않습니다.
- 모든 탭을 닫으면 유예 시간 뒤 로컬 로그인과 대화 연결이 정리됩니다. 서버 프로세스 종료는 별도입니다.

## 문제가 생겼을 때

| 화면 또는 상황 | 확인할 것과 다음 행동 |
| --- | --- |
| 브라우저 접근 승인 필요 | 실행 도구의 `open --browser chrome`으로 새 창을 엽니다. |
| 로컬 서버에 연결할 수 없습니다 | `python3 tools/local_web.py status`로 서버 실행을 확인합니다. 임의로 두 번째 서버를 켜거나 실행 정보를 지우지 마세요. |
| 대화 연결 종료 | 표시된 단계·상태와 발생 시각을 기록합니다. PC 네트워크를 확인한 뒤 화면의 다시 연결을 사용합니다. 로그인을 반복해서 시도하지 마세요. |
| 절전 이후 연결 종료 | PC가 깨어 있고 네트워크가 돌아왔는지 확인합니다. 자동 대화 재연결은 하지 않습니다. |
| 사진만 표시되지 않음 | 다른 메시지·연결 상태를 확인합니다. 이미지 형식·크기 또는 사진 서버 접근 실패일 수 있으며, 사진 표시 실패만으로 발송을 반복하지 마세요. |
| 시작 옵션을 바꿨는데 그대로임 | 실행 중인 서버는 자동 교체되지 않습니다. 아래 종료·업데이트 순서로 재시작합니다. |
| stop이 종료를 거절함 | 작성 중인 내용을 보관하고 웹 설정에서 로컬 세션을 지운 뒤 다시 종료합니다. 강제 종료로 우회하지 마세요. |

문의에는 OS·발생 시각·화면 문구·`status` 출력·재현 순서·사진 묶음 수를 포함하면 도움이 됩니다. 원본 대화·사진·인증정보·개인 저장소 전체·브라우저 저장소를 첨부하지 마세요. 최신 버전은 재연결 후에도 제한된 수의 정제된 연결 종료 기록을 보존합니다. 저장 범위와 이번 검증은 [안정화 보고서](READINESS_20261025.ko.md)를 확인하세요.

## 종료와 업데이트

1. 작성 중인 초안을 별도로 보관합니다.
2. 웹 설정에서 **로컬 세션 지우기**를 누릅니다.
3. `python3 tools/local_web.py stop`을 실행합니다.
4. 새 소스로 업데이트하고 README의 준비 절차를 확인합니다. 다른 OS에서 만든 런타임·node_modules를 재사용하지 않습니다.
5. `start`→`open`→QR 로그인 순서로 다시 시작합니다.

소스 파일만 교체하거나 브라우저를 새로고침해도 이미 실행 중인 서버 코드는 바뀌지 않습니다. 새 ZIP을 다른 경로에 풀면 설치별 개인 설정 경로도 달라집니다. 이전 설정 폴더를 임의로 덮어쓰지 말고 기존 설치를 보관한 채 필요한 설정을 다시 선택하세요.

## 공유하기 전 확인

배포할 파일은 소스 ZIP입니다. Node·Python·브라우저가 포함된 독립 설치 앱은 아닙니다. ZIP의 `source-package-manifest.json`은 포함된 소스의 SHA-256 목록이며 서명은 아닙니다. `local-only/`·`web-auth/`·`preferences/`·실행 진단·실제 사진을 함께 압축하지 마세요. 새 PC에서는 그 OS의 준비 명령을 다시 실행해야 합니다.
